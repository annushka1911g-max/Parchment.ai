# 🤖 Multi-PDF RAG Chatbot

An AI-powered chatbot that lets users upload multiple PDF documents and ask questions using Retrieval-Augmented Generation (RAG).

## Features

- 📚 Multi-PDF Upload
- 🔍 Hybrid Search (FAISS + BM25)
- 🧠 Gemini 2.5 Flash
- 💬 Conversation Memory
- 📄 Source Citations
- 📥 Chat Export
- 🎨 Professional UI

## Tech Stack

- Python
- Streamlit
- LangChain
- Google Gemini
- FAISS
- BM25
- PyPDF
